# Paired support-criteria simulation

The [runner](runner.py) and [configuration](config.json) use seed **2026101101**.
Seven scenarios use sample sizes 6,000 and 2,000, with 200 datasets per condition.
The same synthetic draws support the comparisons of default, ablated and
short-scale settings.

[Condition-level errors](condition_error_summary.csv) summarize availability,
independent retention, false outputs and conditional reference errors. These
results support the supplementary simulation analysis.
