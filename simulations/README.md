[Condition-level error summaries](support_gate/condition_error_summary.csv)
report output, independent retention, false-output and no-reference rates, and
conditional reference errors. All observations are synthetic.

To run a simulation, use Python 3.11 or newer and install `.[research]` plus `statsmodels`.
The eight-scenario entry point is `python simulations/eight_scenarios/runner.py`.
Run the paired synthetic analysis with:

```bash
python -c "from pathlib import Path; [Path('output/simulations/support-gate', p).mkdir(parents=True, exist_ok=True) for p in ('tables', 'replicates')]"
python simulations/support_gate/runner.py --bundle output/simulations/support-gate --analysis 1
```

Both commands write to ignored `output/` directories. The aggregate error CSV is
a saved result, not regenerated by the paper aggregate entry point.

The [eight-scenario summaries](eight_scenarios/README.md) are extended repository
results; the [paired support summaries](support_gate/README.md) supply eTable 14.
