[Condition-level error summaries](support_gate/condition_error_summary.csv) are copied
unchanged from the paired simulation result bundle: seven scenarios, two sample
sizes, 200 datasets per condition. The table includes output and independent
retention rates, false outputs, no-reference rates, and conditional reference-error summaries.
These files contain no patient records or identifiers. Simulations were not rerun
for this release.

Scientific functions, seeds and numerical settings are preserved. Repository-relative
source/output paths replace the original local layout; the eight-scenario design
configuration replaces the historical notebook in the source-checksum list. Its
configuration changes only the historical notebook's path label. The paired
configuration and error-summary CSV are byte-identical to the saved source files.
The eight-scenario runner retains historical changepoint diagnostics; changepoint
analyses were not used in the manuscript.

For a future run, use Python 3.11 or newer and install `.[research]` plus `statsmodels`.
The eight-scenario entry point is `python simulations/eight_scenarios/runner.py`.
The paired runner also retains ancillary source-bundle functions; run only its
synthetic analysis with:

```bash
python -c "from pathlib import Path; [Path('output/simulations/support-gate', p).mkdir(parents=True, exist_ok=True) for p in ('tables', 'replicates')]"
python simulations/support_gate/runner.py --bundle output/simulations/support-gate --analysis 1
```

Both commands write to ignored `output/` directories. The aggregate error CSV is
a saved result, not regenerated by the paper aggregate entry point.

The [eight-scenario summaries](eight_scenarios/README.md) supply eTable 14A-B;
the [paired support summaries](support_gate/README.md) supply eTable 14C.
Each directory records source hashes and numerical checks.
