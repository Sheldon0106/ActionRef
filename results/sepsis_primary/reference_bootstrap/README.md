# ESRP reference uncertainty

These summaries describe re-estimation of the primary MIMIC and local Stanford
ESRP references in 500 patient-bootstrap resamples per site. Reference candidates,
independently retained outputs, absolute/relative target families and joint
spacing are reported separately.

Conditional reference intervals use the available candidate or independently
retained denominator specified in the table. The full-data point reference is
distinct from a bootstrap median. The primary MIMIC references are 27/39/54;
Stanford local references are 26/36/50.

## Current files

- `reference_pair_stability.csv`

- `reference_point_curves.csv`

Source labels, row selections and file checksums are recorded in
[manifest.json](manifest.json). All shared observations are aggregates; patient
records and identifiers are not included.
