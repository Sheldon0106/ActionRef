# Fixed-policy operating uncertainty

These tables report operating estimates and patient-cluster intervals for the
fixed ESRP references 27/39/54 and selected revised threshold 34. Each policy is evaluated
with 1,000 requested resamples per cohort.

The paired comparisons of threshold 34 with 27 and 31 use shared patient
resamples within each evaluation cohort and fix R at 11,299/804. The threshold
exchanges divide the added false-positive alerts by the added sepsis-positive
encounters flagged when the threshold is lowered. This ratio gives the R at
which the two fixed thresholds have equal FAE.
