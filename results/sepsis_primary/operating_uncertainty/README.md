# Fixed-policy operating uncertainty

These tables report operating estimates and patient-cluster intervals for the
fixed ESRP references 27/39/54 and selected revised threshold 34. Each policy is evaluated
with 1,000 requested resamples per cohort.

The 34-minus-27 FAE intervals use differences from shared cohort and resample IDs,
not subtraction of marginal confidence limits. They quantify uncertainty for the
fixed policies; candidate-selection uncertainty is a separate question.
