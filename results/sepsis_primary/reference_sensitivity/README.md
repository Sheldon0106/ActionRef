# Reference-setting sensitivity

These point-estimate summaries vary probability targets, binning and support or
evidence-gate settings one at a time. The analyses describe sensitivity to the
specified settings; package defaults remain unchanged.

The tolerance rows replay a historical numerical rule and are identified
separately from the default package settings.

## Current files

- `semantic_gate_one_factor_sensitivity.csv`
- `semantic_target_selection.csv`

## Retained historical files

These earlier values or definitions are retained for historical reference and are
not inputs to the current summaries.
- `semantic_target_variant_registry.csv`

Source labels, row selections and file checksums are recorded in
[manifest.json](manifest.json). All shared observations are aggregates; patient
records and identifiers are not included.
