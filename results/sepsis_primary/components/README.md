# Recorded-action components

These tables describe component prevalence, action patterns, component-specific
curves and references, and changes when a component is omitted. The primary
composite retains heterogeneous source windows. Component percentages use the
complete-component or action-known denominators identified in each table.

Stanford local component references use the standalone component learner with
100 requested resamples per component. Candidate availability, shared thresholds
and available-level ordering describe different aspects of the output. The
component learner's ordering field is not a count of complete three-reference
outputs. Local component estimates and evaluations of transported MIMIC component
references are separate analyses.
