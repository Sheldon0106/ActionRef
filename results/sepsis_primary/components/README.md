# Recorded-action components

Manuscript locations: **eTables 4 and 7**.

## Checks against the final manuscript

MIMIC lactate-only references are 27 / 39 / 54. Removing lactate gives 21 / 63 / 72. Lactate is present in 87.40% of composite-positive learning encounters, and is the only positive component in 73.09%. Stanford local lactate references are 26 / 38 / 50.
